## 👨‍💻 About Me

> *"I don't just write code, I architect digital ecosystems that solve real problems."*

I'm a **Fullstack Developer & Web Dev Instructor** at **SMK TI Dwiguna** since 2021, based in Bogor, Indonesia 🇮🇩. I build school systems students rely on daily and teach the next generation of developers. My work ranges from AI-integrated helpdesk systems to facial recognition guestbooks and geolocation-based attendance.

Graduated from **AMIK Wahana Mandiri** (D3 Informatics Management, 2024). Beyond coding, I mentor students and junior developers in MVC architecture, database design, and API development.
